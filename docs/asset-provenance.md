# Asset Provenance

## Bundled Theme Previews

The `workbench`, `night-shift`, `arcade-signal`, and `quiet-garden` preview PNGs
were rendered specifically for Codex Habitat from their committed semantic
color tokens. They contain original geometric interface artwork only.

- Created: 2026-07-17
- Tooling: deterministic Pillow raster rendering with the bundled Codex Python runtime
- Generative model input: none
- Third-party artwork: none
- License: MIT, as recorded beside each theme

The previews are illustrative theme samples. They are not screenshots of Codex,
do not contain user data, and do not include installed pet artwork.

## Application Icon

`Assets/AppIcon.png` and `Assets/AppIcon.icns` are original geometric artwork
created for Codex Habitat. The icon combines a macOS window silhouette with a
small Habitat robot using the Workbench semantic colors.

- Created: 2026-07-17
- Tooling: deterministic AppKit drawing in `scripts/generate-app-icon.swift`
- Generative model input: none
- Third-party artwork or trademark asset: none
- Source output: 1024 x 1024 RGBA PNG and standard multi-resolution ICNS

## Overlay Visual References

The four PNG files in `Tests/VisualReferences` were captured from deterministic
local overlay fixtures at 720 x 360. They contain no official Codex screenshot,
installed pet art, account information, prompts, responses, paths, or raw IDs.
